# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/jsundquist/transcript-search-mcp/security/advisories/new).

Do not open a public issue or pull request for a suspected vulnerability.

## Supported versions

Only the latest commit on `main` is supported. There are no tagged releases or published packages.

## Response time

Reports are acknowledged within 7 days. A fix or mitigation is targeted within 30 days, depending
on severity. This is a personal project maintained on a best-effort basis.
